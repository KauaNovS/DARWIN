# DARWIN — Sistema Operacional de Evolução Humana

> *"Você não precisa ser motivado. Você precisa ser estruturado."*

Darwin é um sistema de evolução psicológica real, inspirado na mecânica dos Beyonders de **Lord of Mysteries**.
Desenvolvido por uma equipe elite de psicólogos, terapeutas, psiquiatras, nutricionistas e filósofos.

---

## Arquitetura

```
darwin/
├── web/          # Next.js 14 — App Router, TypeScript, Tailwind
│   ├── app/      # Páginas e API Routes
│   ├── prisma/   # Schema PostgreSQL
│   └── ...
└── mobile/       # Expo React Native
```

## Stack

- **Web/API:** Next.js 14 + TypeScript + Tailwind
- **Banco:** PostgreSQL via Neon + Prisma ORM
- **Mobile:** Expo SDK 51 + React Native
- **IA:** Anthropic Claude (análise de digestão, missões, corrupção)
- **Auth:** JWT + bcrypt
